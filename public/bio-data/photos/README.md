Drop photos for the /bio-data "View photos" gallery in this folder.

- Accepted: .jpg, .jpeg, .png, .webp, .avif
- Shown in filename order, so name them 01-*.jpg, 02-*.jpg, …
- The filename (minus extension, dashes/underscores as spaces) is used as the alt text
- Nothing else is needed: the page lists this folder at build time
